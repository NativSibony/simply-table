# Documentation Site

This directory contains the documentation website for simply-table.

## Setup

This is a standalone documentation site that is completely separate from the library build process.

You can set up your documentation site here using any static site generator or framework of your choice (e.g., VitePress, Docusaurus, Next.js, etc.).

## Important

- This directory is excluded from the npm package
- It does not affect the library build process
- It has its own independent configuration
